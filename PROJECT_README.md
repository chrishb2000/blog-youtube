# Sabor & Tradición - Blog Gastronómico Profesional

## 🍳 Descripción

**Sabor & Tradición** es un sitio web profesional para un food blogger/youtuber especializado en gastronomía mundial. El sitio presenta recetas, técnicas culinarias, tradiciones alimentarias, ingredientes y cultura gastronómica.

**Autor:** Christian Herencia  
**Website:** [https://christian-freelance.us/](https://christian-freelance.us/)

## 🚀 Instalación y Uso

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Servidor web (opcional, funciona directamente en navegador)

### Pasos

1. **Clonar/Descargar el proyecto**
   ```bash
   cd comida
   ```

2. **Generar las imágenes con IA**
   - Revisar el archivo `IMAGE_PROMPTS.md`
   - Usar Midjourney, DALL-E 3, o Stable Diffusion
   - Guardar imágenes en la carpeta `images/`

3. **Abrir el sitio web**
   - Opción A: Abrir `index.html` directamente en el navegador
   - Opción B: Usar un servidor local (Live Server, XAMPP, etc.)

### Servidor Local Recomendado

**VS Code Live Server:**
1. Instalar extensión "Live Server"
2. Click derecho en `index.html`
3. Seleccionar "Open with Live Server"

## 🎨 Generación de Imágenes

El archivo `IMAGE_PROMPTS.md` contiene todos los prompts necesarios para generar las imágenes con IA:

- **Hero Carousel:** 4 imágenes principales (paella, tacos, sushi, pasta)
- **Categorías:** 6 imágenes (recetas, ingredientes, tradición, técnicas, cultura, videos)
- **Artículos:** Múltiples imágenes para posts
- **Trending:** 4 imágenes populares
- **Equipo:** 4 fotos de miembros del equipo
- **Portafolio:** Varias imágenes de proyectos
- **Video Thumbnails:** 4 miniaturas de YouTube
- **Y más...**

**Recomendaciones:**
- Resolución mínima: 1920x1080px
- Formato: JPG 80-90% calidad
- Optimizar con TinyPNG antes de usar

## 🔧 Personalización

### Cambiar Colores

Editar las variables CSS en `css/styles.css`:

```css
:root {
    --color-primary: #c44536;      /* Color principal (rojo) */
    --color-secondary: #f39c12;    /* Color secundario (naranja) */
    --color-accent: #27ae60;       /* Color de acento (verde) */
}
```
